About the IBM Supervised Machine Learning: Regression Course

Offered by IBM Skills Network on Coursera as Course 2 of the IBM Machine Learning Professional Certificate, this course trains data scientists to move beyond black-box predictions and communicate rigorous, statistically sound regression findings to stakeholders.

Module 1: Simple & Multiple Linear Regression

Formulating the Gauss-Markov linear model, Ordinary Least Squares (OLS) closed-form normal equations, interpreting slope coefficients (β), and diagnosing Variance Inflation Factors (VIF).

Module 2: Train/Test Splits, K-Fold CV & Polynomials

Preventing data leakage with Z-score StandardScaler fitted on training folds, K-Fold Cross-Validation, and modeling non-linear curvature via PolynomialFeatures.

Module 3: Regularization (Ridge L2, Lasso L1, ElasticNet)

Controlling the bias-variance trade-off: L2 weight decay (RidgeCV) to stabilize collinear predictors, L1 sparsity (LassoCV) for automatic feature selection, and ElasticNet hybrid penalties.

Module 4: Residual Diagnostics & Stakeholder Reporting

Testing homoscedasticity, residual normality (Shapiro-Wilk & Q-Q plots), target transformations (Box-Cox / Log-link GLM), and translating statistical metrics into executive insights.

[2] Analysis Objective, Hypotheses & Multicollinearity (VIF) Challenge

We aim to predict 1-year Disease_Progression while isolating the true clinical effect of each biomarker despite severe multicollinearity in the lipid panel (VIF up to 59.20).

[5] Evaluation, Model Limitations & Future Improvements

Identified Model Flaw / Limitation Empirical Diagnostic Evidence Concrete Plan to Revisit & Improve Analysis
1. Omitted Clinical Confounders (~49% Unexplained Variance) Best R² caps at 0.5042 (RMSE = 51.25, MAE = 40.85). Collect longitudinal HbA1c, insulin dosage, CGM time-in-range, diet, and genetic risk scores.
2. Mild Heteroscedasticity in Mid/High Range Residual SD is 46.85 for predictions <150 vs. 58.92 for predictions ≥150. Apply a Box-Cox / logarithmic target transformation or fit a Gamma GLM with a log link.
3. Single Cross-Sectional Baseline Snapshot Features measured only at t = 0; rate of prior BMI/lipid change is unknown. Incorporate longitudinal panel data with mixed-effects / time-series regression.
4. Point-Prediction Uncertainty Standard linear regression outputs a single score without confidence bounds. Fit Quantile Regression (10th/50th/90th percentiles) and benchmark against XGBoost + SHAP.

Engineering Post-Mortem: 4 Real Errors Encountered & How We Solved Them

During the development and submission of this project across local Windows, browser-based JupyterLite, and Coursera's automated AI Grader, we encountered and resolved four critical engineering obstacles.

Error #1: Unsaved 0-Byte Specification File & Residual Placeholder SyntaxError

SyntaxError: invalid syntax (Cell In[1], line 68) RESOLVED

Initially, the local instruction text file was 0 bytes (unsaved buffer in Notepad), and pasting code into Cell 1 without selecting all existing text left the trailing substring "an add this a markdown cell." attached to plt.show(), preventing Cell 1 from executing and causing downstream NameError in Cell 4. 

# Broken Line 68:
plt.show()an add this a markdown cell.  # <-- Leftover template text caused SyntaxError

# Fix Applied:
# 1. Replaced entire cell buffer cleanly (Ctrl+A -> Ctrl+V)
# 2. Made every cell self-sufficient and pre-populated all .ipynb cell sources cleanly.

Error #2: Browser JupyterLite Kernel Missing sklearn & scipy Packages

ModuleNotFoundError: No module named 'sklearn' / 'scipy' RESOLVED

Running inside an unprovisioned browser kernel raised ModuleNotFoundError for scikit-learn and scipy. We solved this both by building a pure-Python coordinate descent fallback for unprovisioned kernels AND by pre-executing the full scikit-learn/scipy pipeline and saving the rendered outputs directly inside the .ipynb JSON so uploading requires zero re-execution.

Error #3: Dark-Mode White-on-White Text Collision & RTL Table Flipping

UI Contrast & RTL Inheritance Bug RESOLVED

When viewing HTML tables inside a Dark Mode editor on an Arabic OS, light row backgrounds (#f4f8fb) inherited white dark-mode text (#ffffff), making numbers invisible, while Arabic browser defaults flipped English tables right-to-left (RTL). We enforced explicit dir="ltr", direction:ltr, color:#111111, and background-color:#ffffff on every container and cell.

Error #4: Coursera AI Grader Partial Score (1/10) on Single-Question File Upload

Rubric Evaluation: 1/10 on finalassigment-finsh 1.ipynb RESOLVED → 10/10 IN finalassigment-finsh.ipynb

Uploading finalassigment-finsh 1.ipynb alone resulted in 1/2 on Section 1 and 0/2 on Sections 2–5 because Coursera evaluates all 5 criteria from a single master notebook, checks for authentic dataset loading (load_diabetes instead of random.gauss loops), requires explicit Hypotheses & Challenges in Section 2, and inspects pre-saved cell outputs. All requirements are now unified and pre-executed in finalassigment-finsh.ipynb.
