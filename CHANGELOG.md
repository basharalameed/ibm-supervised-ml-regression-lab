# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-11-07
### Added
- **`finalassigment-finsh.ipynb`**: Complete 10/10 Coursera submission notebook covering all 5 rubric sections (`[1] Dataset Description`, `[2] Analysis Objective`, `[3] Model Comparison`, `[4] Findings & Interpretation`, `[5] Evaluation & Future Steps`) with pre-saved outputs.
- **`index.html`**: Interactive bilingual (`EN ↔ AR`) GitHub Pages showcase featuring a 3D WebGL regression surface (`Three.js`), live clinical risk simulator, interactive 5-task tabs, and engineering post-mortem.
- **`README.md` & `README_AR.md`**: Comprehensive bilingual documentation with architecture diagrams, model benchmark tables, and post-mortem analysis.
- **Modular Study Notebooks (`finalassigment-finsh 1..5.ipynb`)**: Individual notebooks for each of the 5 evaluation tasks.
